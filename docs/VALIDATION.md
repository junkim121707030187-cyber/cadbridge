# 검증 계획과 완료 관문
기준: [요구사항](REQUIREMENTS.md). 이 문서는 향후 시험 계획이며 현재 CAD/API 실행 결과가 아니다. CAD쌍·버전·최종 부품·모든 최종 판정 수치는 공식자료 조사·추천안 검토 전 TBD(미정)다.

## 관문
| 관문 | 진입·수행 | 완료 조건 |
|---|---|---|
| G0 준비 | CAD 프로그램 두 개의 공식자료·API·라이선스·저장 형식 조사 | 선정 근거와 지원 범위 기록; 라이브러리를 프로그램 두 개로 세지 않음 |
| G1 native 수동계획 | 대상 CAD에서 알려진 부품의 피처·스케치·치수·제약 생성 | save→close→reopen→edit→rebuild 후 변경 저장·재확인, 입력·버전·증거 보존 |
| G2 단방향 통합 | A 부품을 B native로 재구성 | B에서 지정 수정·저장·재열기·재계산과 V 시험 통과; 손실 공개 |
| G3 평가 | 사전 고정한 부품·조건·판정 기준 적용 | 사례별 성공·실패·제약·의도 판정을 분리 보고 |

G1은 도구 기능과 재현 경로의 관문이다. 정답 피처 계획을 제공한 G1 통과를 STEP 의도 추론 성능으로 계산하지 않는다. G2도 첫 제품 장면의 검증이며 장기 협업 전체 완성은 아니다.

## 실험군과 시험
STEP-only 군은 STEP 기하와 사전 선언한 사용자 요구만 사용한다. native 정보 이용 군은 원본 피처·스케치·제약 등 실제 사용한 추가 정보를 기록한다. 두 군의 입력·정답 노출·사람 개입·부품 난이도를 분리하며 성공률을 합치지 않는다. 정답 의도를 아는 제작 예제는 기능 확인용으로 따로 표시한다.

| 시험 | 관측·판정 | 연결 |
|---|---|---|
| V-N native | 피처·스케치·치수·제약 존재, 지정 치수 변경과 종속 형상 재계산, 저장·종료·재열기 후 지속성 | R-01,R-02 |
| V-G 형상 | 단위·좌표, 거리·부피·위상 등 선정 지표, 실패·수치 불안정 별도 판정 | R-10,R-11 |
| V-I 의도 | 보호 관계·편집 동작·후보 근거, 모호성 선택 전 보류; 편집실행과 의도일치 분리 | R-03,R-05 |
| V-P 권한 | 조건 위반·무선택·무권한·낡은 승인·권한 밖 대체 차단, 허용 대체 공개 | R-04,R-05,R-06,R-12 |
| V-C 맥락 | 입력·출처·측정·요구·가정·선택·대체·출력 연결 재조회, 누락 검출 | R-03,R-06,R-07,R-08 |
| V-F 실패 | 손상·미지원·솔버 불능·CAD 오류·저장 실패에 원본·마지막 유효 상태 보존 | R-09 |

## 공차를 분리한다
| 종류 | 의미 | 현재 값 |
|---|---|---|
| 제조 공차 | 설계가 허용하는 제작 편차 | 미정 |
| 입력·기하 공차 | 파일 해석·측정·커널 처리 기준 | 미정 |
| 재구성 검증 허용오차 | 원본과 결과 비교 판정 기준 | 미정 |
| 솔버 잔차 | 제약 수치 해의 허용 잔차 | 미정 |

각각 단위·절대/상대 기준·적용 대상·판정 절차를 정하고 상충 시 실패로 보고한다. 과거 0.01mm와 상대 대칭차부피 1e-6은 새 합의값이 아니다. 기준 미정 상태의 결과는 탐색 결과로만 기록한다.

향후 실행 증거에는 요구·시험 ID, 입력과 결과 해시, 입력 정보군, CAD/도구/모델 버전, 실제 실행 절차·시각·로그·화면 또는 파일 근거, 기대값·실측값·판정·사람 개입을 남긴다. 외부 모델 실제 추론과 저장 후보를 반환하는 mock 시험을 구별한다. 이번에는 [문서 검사](STATUS_AND_EVIDENCE.md)만 수행한다.
