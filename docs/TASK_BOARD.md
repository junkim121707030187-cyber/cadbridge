후속 사용자 구현 요청으로 위 T1~T4의 제한된 첫 코드를 진행했다. 일반 제품 수준의 G0~G3 완료를 뜻하지 않는다. 원 M3 재사용은 별도 소스 회수·해시·권리·실행 환경 확인부터 시작한다. 과거329/87 기록을 신규 통과 증거로 붙이지 않는다.

제품 결정이 필요한 것은 보호 조건·대체 허용 범위·판정 기준·추천안 선택 등이다. [개념도와 미정 목록](PRODUCT_CONCEPT.md)에서 확인한다. 공식자료 조사, JSON 필드, 함수 계약, 테스트 구현, 기술 비용·위험 비교는 엔지니어가 준비한다. 정본은 사용자가 지정한 비공개 [cadbridge 저장소](https://github.com/junkim121707030187-cyber/cadbridge)의 main에 반영했으며 commit·검사 결과는 [상태·근거](STATUS_AND_EVIDENCE.md)를 따른다. 협업 승인 정책·장기 지원 주체는 미정으로 관리한다.
