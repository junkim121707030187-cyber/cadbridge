# 작업 환경 검토 기록
문서 버전 1.2.1 · 2026-11-16 KST

## 검토 범위
참고 저장소의 협업 방식과 기존 CADBridge 합의를 비교하고 작업 규칙·역할·경로 배정·계약 변경·검토·인계·비밀 관리·문서 검사·CI를 준비했다. 주 작업자와 별도 검토 에이전트가 문서를 읽었다. 별도 에이전트는 검사 도구 작성도 맡았으므로 도구 전체의 독립 검토로 부르지 않는다.

## 실제 수행
- Python 표준 라이브러리 검사 실행: 파일·UTF-8·JSON·상대 링크·요구 ID·충돌 표시·비밀 패턴·개인경로·캐시 검사 통과.
- 검사 도구 Python 문법 확인, CI YAML 파싱·읽기 전용 권한 확인.
- 도구 작성자의 임시 fixture 검사 보고: 정상 입력 통과, 깨진 링크/앵커·미정의 요구·잘못된 해시·비밀 키·.env·캐시·UTF-8 오류 거부.
- 최종 패키지는 manifest SHA256·크기·복원 JSON 내용 일치·ZIP 추출 바이트 일치 검사 후 전달한다. 실제 파일 수와 결과는 manifest의 review에 기록한다.

## 한계
패턴 검사는 포괄적인 비밀 탐지 보증이 아니다. 문서의 역할·권한 규칙은 실제 동시성 잠금·인증·branch 보호를 구현하지 않는다. GitHub CI 정의를 준비했으며 원격 실행은 업로드 후 별도로 확인해야 한다. CAD·외부 LLM 제품 시험·프로그램 설치·M3 소스 회수는 수행하지 않았다.

## 원격 진행
1.2.0 당시 요청에 따라 브라우저 작업·자동 저장소 생성·업로드를 중단하고 직접 업로드용 파일을 제공했다. 당시 GitHub 계정 조회는 성공했고 설치된 저장소에서 cadbridge 검색 결과는 0개였다. 이는 모든 GitHub 저장소의 부재를 증명하지 않는다. 제공된 도구에는 파일·커밋·브랜치·PR 기능이 있고 저장소 생성 기능은 없다. 이후 사용자가 저장소를 생성해 URL을 지정하고 업로드를 재요청했다. 현재 진행은 아래 1.2.1 기록을 따른다.

## 1.2.0 제품 개념도
[제품 개념도](PRODUCT_CONCEPT.md)에 제품 흐름·데이터와 컨텍스트 관계·장기 협업 목표 및 미정 항목을 정리했다. 합의된 제품 동작과 제안한 모듈 구조를 구분했다. Mermaid 원문과 문서 연결을 검사하며, GitHub에서의 실제 렌더링은 업로드 전이므로 미확인이다. 문서 검사·해시·복원 JSON·ZIP 바이트 검증 결과는 manifest의 review에 기록한다.

개념도 작성자는 그 외 갱신 문서를 별도로 검토했고 에이전트 절차에 남아 있던 과거 원격 진행 문구 1건을 발견했다. 최신 중단 범위로 수정했다. 업로드 후에도 해시 검사가 가능하도록 복원 JSON은 manifest의 필수 내부 파일 목록과 분리했다. 이 검토는 개념도 작성자 자신의 그림에 대한 독립 검토로 부르지 않는다.

## 1.2.1 원격 업로드 검토
사용자 지정 비공개 cadbridge의 main·쓰기 권한·초기 README를 확인했다. 초기 커밋을 부모로 유지한 b5ccbe09dfc3cf4545f86cbe7f4aeef23551836b에 정본 33개를 올리고 main ref를 재조회했다. 원격 반영 전 로컬 문서·UTF-8·상대 링크·요구 ID·비밀 패턴·해시 검사를 통과했고, 원격 트리 파일 33개의 blob 해시를 로컬 바이트와 대조해 모두 일치했다. 제품 개념도를 원격에서 다시 읽어 원문 일치도 확인했다. 해당 초기 커밋의 GitHub Actions 문서 검사 실행 43802258010은 completed/success로 확인했다. [상태·근거](STATUS_AND_EVIDENCE.md)에 commit과 실행 링크를 기록했다. CAD/API 제품 시험은 수행하지 않았다.
