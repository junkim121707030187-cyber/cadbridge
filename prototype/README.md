# CADBridge 로컬 통합 시제품 · 2026-11-16

각 Windows PC에서 파일·형상·대화와 버전을 관리해 보는 MVP입니다. 현재 코드와 예제를 업로드한 상태이며, 이번 업로드 과정에서는 새 PC 설치나 실행 확인을 하지 않았습니다.

## 각 PC에서 열기

1. 저장소의 **Code → Download ZIP**으로 내려받고 압축을 풉니다.
2. **Python 3.11 이상**이 설치된 Windows에서 이 `prototype` 폴더를 엽니다.
3. PowerShell에서 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1`을 한 번 실행합니다. Python 환경·의존성과 공식 FreeCAD 휴대용 배포본을 내려받으므로 인터넷과 충분한 디스크 공간이 필요합니다. 이 명령의 정책 설정은 해당 프로세스에만 적용됩니다.
4. `Start.cmd`를 실행하면 브라우저에서 워크스페이스가 열립니다. 기본 주소는 `http://127.0.0.1:8787/workspace`이며, 포트 충돌 시 뒤 번호를 사용합니다.
5. 종료는 `Stop.cmd`를 사용합니다.

기존 `runtime` 폴더는 업로드하지 않았으므로, 처음 받은 PC는 `Start.cmd` 전에 설치 과정이 필요합니다. 새 PC에서의 설치 성공은 아직 확인하지 않았습니다. 현재 런처·설치 경로는 Windows용이며 macOS/Linux 배포는 준비하지 않았습니다.

## 먼저 볼 것

- **설계-검토 → 형상 → CB-P01 플레이트**에서 실제 저장된 두 버전을 선택합니다.
- 파일함·댓글·답글·검색·고정·ZIP 내보내기를 살펴봅니다.
- [AI 예제 설명](examples/AI_EXAMPLE.md)에서 입력 STEP, Terra의 구조화된 응답, native 모델과 편집 결과를 비교합니다.
- [워크스페이스 사용 안내](워크스페이스_사용안내.html)와 [CAD 도구 사용 안내](사용안내.html)를 참고합니다.

저장된 AI 결과는 로그인 없이 파일로 확인할 수 있습니다. **새 Terra 추론 실행**에는 해당 PC의 Codex 실행기·로그인·모델 접근 권한이 별도로 필요합니다. 사용자 계정·토큰·Codex 설정은 포함하지 않았습니다.

## 범위와 저장

이 앱은 **로컬 단일 사용자**용입니다. 각자의 파일과 대화는 각 PC의 `data/workspace`에 저장되며 팀원 간 자동 동기화되지 않습니다. `127.0.0.1` 참조 링크는 같은 PC에서 열립니다. 외부 자료 전달은 ZIP 내보내기를 이용합니다. 새 파일 등록이나 작업 상태 변경은 CAD 기하 검증을 의미하지 않습니다.

동봉한 `data/workspace`는 예제와 로컬 시연 기록의 배포용 스냅샷입니다. ‘신규 부품 검토안’은 텍스트 메모를 묶은 CAD 미검증 예제입니다. 실제 기하 재구성 예제는 CB-P01 하나입니다. 로그인·권한 관리·실시간 공동 편집·범용 CAD 자동 분할은 구현하지 않았습니다.

## 검증 기록

기존 개발 PC에서 수행한 결과는 `evidence/validation.json`, `evidence/workspace-validation.json`, `evidence/gui-open-verification.json`에 보존했습니다. 최근 소프트웨어 검사 기록은 65개 함수와 하위 사례 194개 통과입니다. 이는 실제 CAD 실행 횟수가 아닙니다. **이번 GitHub 업로드에서는 실행 검사를 추가로 하지 않았습니다.** 현재 통합 앱의 검사는 `tests/`에 포함했고, 이번에 실행하지 않은 과거 M3 소스의 별도 테스트 폴더는 배포에서 제외했습니다.
