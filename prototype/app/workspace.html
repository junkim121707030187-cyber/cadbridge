부품이나 주제별로 대화와 파일을 모아 보세요.

형상 작업 만들기

관련 파일을 묶고 버전과 설계 댓글을 이어갑니다. CAD 형상 생성은 모델 도구에서 실행하세요.

새 버전 등록

업로드된 파일을 하나의 버전으로 기록합니다. 파일 등록만으로 CAD 형상이나 제약이 검증되지는 않습니다.

설계를 이어가는 공간

현재 기기에 파일과 대화, 형상 버전, 설계 댓글을 저장하는 로컬 시제품입니다.

① 채널에서 대화하고 파일을 올려요.
② 파일이나 형상을 선택해 설계 맥락을 확인해요.
③ 버전과 요소에 댓글을 남겨 전달할 조건을 기록해요.
④ ZIP으로 내보내 파일과 기록을 전달해요.

로그인·실시간 다인 협업·공개 공유 서버는 제공하지 않습니다. ‘나’는 이 기기의 사용자 표기입니다. 예제 형상은 하나의 CB-P01 시험 부품이며 실제 저장된 버전만 표시합니다.
