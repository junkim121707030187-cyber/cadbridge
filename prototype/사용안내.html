CADBridge 시제품

STEP의 측정값과 설계 조건으로 Terra가 후보를 만들고, 그 후보를 실제 편집 가능한 FreeCAD 모델로 저장하는 로컬 시제품입니다.

  1. 이 폴더의 Start.cmd를 두 번 클릭하세요. 화면이 열리면 예제 부품으로 시작하거나 STEP 파일을 선택합니다.
  2. 반드시 유지할 조건을 입력한 다음 Terra로 설계 후보 만들기를 누릅니다. 현재 로그인된 Codex의 gpt-6.1-terra를 사용합니다. 측정값과 설계 조건이 이 에이전트에 전달됩니다.
  3. 후보의 근거와 가정을 확인하고 이 후보로 FreeCAD 모델 만들기를 누릅니다. 모델을 저장하고 별도 프로세스에서 다시 열어 확인합니다.
  4. 판 두께, 홀 지름, 홀 X 간격을 바꾸고 수정하고 새 버전 저장을 누릅니다. 원본과 이전 정상 버전은 보존됩니다.
  5. FreeCAD에서 열기로 실제 스케치·피처·제약을 확인하고 직접 편집할 수 있습니다. 모델 트리의 Parameters에서 Thickness, HoleDiameter, PitchX 등을 바꿀 수 있습니다. FreeCAD에는 원본 버전을 보존하는 별도 작업본을 열어 줍니다. FreeCAD에서 직접 바꾼 작업본을 앱 버전에 자동으로 다시 반영하는 기능은 아직 없습니다.

이 PC에서는 실행 중인 작업 화면으로 접속할 수 있습니다. 종료는 Stop.cmd를 실행하세요. 브라우저만 닫아도 파일은 남으며, 서버를 종료하려면 Stop.cmd를 사용합니다.

현재 사용할 수 있는 범위

원점 중심의 XY 정렬 사각 판재, 최대 한 개의 중앙 사각 막힌 포켓, 동일 지름의 대칭 2×2 Z축 관통 홀을 지원합니다. 임의의 CAD 부품, 필렛·곡면·기울어진 형상, 조립체는 지원하지 않습니다. 지원 밖의 형상은 자동으로 단순화하지 않고 거부합니다. 입력 STEP의 길이 단위는 측정 엔진에서 mm로 다룹니다.

SALOME SHAPER 이전, 상용 CAD, 다인 협업은 이번 실행 범위에 포함되지 않습니다. 합의한 후속 경로는 FreeCAD 1.1.4 → SHAPER 9.16.0으로 유지합니다.

에이전트 연결이 안 될 때

Codex에 로그인되어 있어야 자동 Terra 요청을 할 수 있습니다. 화면의 ‘분석 요청·응답 파일로 이어가기’를 펼쳐 요청 JSON을 이 채팅에서 Terra에게 읽게 하고, 구조화된 응답 JSON을 가져올 수도 있습니다. 직접 가져온 응답의 모델 신원은 미검증으로 기록합니다. 연결 실패를 저장 후보 재생이나 새 모델 추론 성공으로 표시하지 않습니다.

검증과 한계

실제 STEP 관측 → Terra 후보 → IR/출처 검사 → 제약 풀이 → native 스케치·피처 생성 → 저장·새 프로세스 재열기 → 치수 수정·재저장까지 이 Windows PC의 FreeCAD 1.1.4에서 확인했습니다. 시연 입력은 합성 CB-P01 부품입니다. 보존된 후보를 사용한 재실행과 실제 새 Terra 호출 기록을 구분해 보관합니다.

재구성 비교는 주요 치수·위치와 양방향 유한 표면 샘플의 거리 ≤0.01 mm, 입력 BRep 내부 공차 <0.002 mm를 확인합니다. 연속 표면 전체에 대한 엄밀한 최대 오차 증명이나 다른 기하 커널의 독립 검증은 아닙니다. 제조 공차·강도·제조성의 승인도 아닙니다.
