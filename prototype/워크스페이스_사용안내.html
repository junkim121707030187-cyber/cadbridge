채널에서 대화하고, 파일과 부품별로 버전과 메모를 모아 보는 간단한 작업 공간입니다. Slack의 채널 구성을 모티브로 하되, CAD 파일과 형상을 찾고 검토하는 흐름에 맞췄습니다.

지금 워크스페이스 열기 · 꺼져 있으면 Start.cmd를 실행하세요.

먼저 해보기

  1. 왼쪽에서 채널을 선택하고 대화와 등록된 파일을 확인합니다.
  2. 형상에서 CB-P01 플레이트를 엽니다. 같은 부품의 두 버전을 바꿔 보며 3D 미리보기와 치수를 확인합니다.
  3. 부품 전체, 포켓, 홀 패턴 중 검토 대상을 선택하고 메모를 남깁니다. 같은 대상의 메모를 모아서 볼 수 있습니다.
  4. 파일함에 파일을 올리고 관련 형상에 연결합니다. 새 파일을 형상의 새 버전으로 등록할 수 있습니다.
  5. 공유 링크로 같은 환경에서 파일이나 형상을 바로 열거나, ZIP으로 내보내 자료를 전달합니다.

파일과 형상은 이렇게 연결됩니다

형상검토할 부품, 관련 파일, 버전, 검토 상태와 특징별 메모
버전특정 시점의 파일 묶음과 변경 메모. 이전 파일을 덮어쓰지 않습니다.

기존 CAD 도구와 함께 사용하기

샘플 부품은 앞서 실제로 검증한 FreeCAD 결과를 가져옵니다. 모델 도구에서는 STEP 분석, Terra 후보, 모델 생성과 치수 수정을 이어갈 수 있습니다. 워크스페이스에서 파일을 등록하거나 검토 상태를 바꾸는 행동은 CAD 재계산이나 기하 검증과 별개입니다.

현재 범위

현재는 이 PC에서 실행하는 한 사용자용 시제품입니다. 사용자 이름은 실제 신원 인증을 의미하지 않으며, 여러 사람이 원격으로 동시에 접속하는 서비스와 권한 관리 기능은 아직 없습니다. 공유 링크의 127.0.0.1은 현재 기기에서 열립니다. 다른 사람에게는 내보낸 파일을 전달해야 합니다.

새로 올린 파일에서 조립체나 피처를 자동으로 나누지는 않습니다. 형상과 파일의 연결은 사용자가 정하고, STL 등 미리보기 자료가 있는 경우 3D 형상을 표시합니다. 예제의 포켓과 홀 패턴은 실제 검증한 모델의 기록을 바탕으로 합니다.

작업 내용은 CADBridgePrototype의 data/workspace에 저장됩니다. 기존 CAD 시제품의 원본 프로젝트와 검증 결과는 별도로 보존합니다. Stop.cmd로 로컬 앱을 종료할 수 있습니다.
